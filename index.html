About Class 10 Test Portal

10

Class 10 Test Portal

Version 1.0.0 • Premium Educational Platform

Class 10 Test Portal is a comprehensive, modern educational platform designed specifically for Class 10 students following the CBSE/NCERT curriculum. It offers an immersive test-taking experience with AI-powered question generation, real-time leaderboards, detailed performance analytics, and gamification features to keep students motivated.

Built with cutting-edge web technologies including Firebase for real-time synchronization, PWA capabilities for offline access, and a beautiful glassmorphism UI with neon accents, the platform delivers a premium learning experience across all devices.

Key Features

  • 7 Core Subjects with all NCERT chapters
  • AI Question Generator (Gemini-powered)
  • Real-time Leaderboard & Rankings
  • Detailed Performance Analytics
  • Offline Test Taking with Auto-Sync
  • Gamification: XP, Coins, Levels, Badges, Streaks
  • Daily Challenges & Weekly Tests
  • PWA — Install as an app
  • Dark/Light themes with accessibility support

Technology Stack

Firebase Authentication, Firestore, Cloud Storage, Cloud Functions (Gemini proxy), Vanilla JS, Service Workers, Canvas API for visualizations.
